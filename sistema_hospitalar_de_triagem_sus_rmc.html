                    Como conectar esta tela HTML direto à sua FastAPI local
                

                
            

            

                

                    Por padrão, os navegadores bloqueiam chamadas feitas de um arquivo HTML para http://127.0.0.1:8000 se o servidor FastAPI não tiver o cabeçalho CORS habilitado.
                

                

                    Eu já atualizei o seu arquivo api_permanencia.py com o CORSMiddleware liberado! Basta garantir que o seu api_permanencia.py contenha estas linhas logo após criar o app = FastAPI(...):
                

                
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],
)

                

                    Em seguida, mantenha o servidor rodando no terminal com:
                

                
python -m uvicorn api_permanencia:app --reload --port 8000
